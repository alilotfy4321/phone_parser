# 📱 Smart Phone Parser

A professional international phone number parsing and validation package for Flutter. Automatically detects country codes, formats numbers, and provides a customizable UI.

[![pub version](https://img.shields.io/pub/v/smart_phone_parser.svg)](https://pub.dev/packages/smart_phone_parser)
[![Dart SDK Version](https://img.shields.io/badge/dart-3.0%2B-blue.svg)](https://dart.dev)
[![Flutter Version](https://img.shields.io/badge/flutter-3.0%2B-blue.svg)](https://flutter.dev)
[![License](https://img.shields.io/badge/license-MIT-purple.svg)](LICENSE)

## ✨ Features

- 🌍 **Automatic Country Detection** - Detects country code from any international number
- 🎨 **Fully Customizable UI** - Use default layout or create your own with builder pattern
- ✅ **Built-in Validation** - Validates phone numbers in real-time
- 🏁 **Flag Emojis** - Shows country flags for better UX
- 📱 **100+ Countries** - Comprehensive country database with ISO codes
- 🔄 **Real-time Parsing** - Updates as user types
- 🎯 **E.164 Format** - Returns standardized international format
- 📝 **Form Integration** - Works seamlessly with Flutter Form widget
- 🚀 **Zero Dependencies** - Only depends on Flutter SDK
